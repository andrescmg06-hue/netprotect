# Historias de usuario

## Sprint 1

- **HU-001**: Como integrante del equipo, quiero un repositorio único y modular para versionar Android, web, backend e infraestructura de forma consistente.
- **HU-002**: Como desarrollador, quiero levantar PostgreSQL, Redis, backend y web mediante configuración reproducible para evitar diferencias de entorno.
- **HU-003**: Como desarrollador Android, quiero que la aplicación compruebe la API central para validar la ruta Android → Backend → PostgreSQL.
- **HU-004**: Como desarrollador web, quiero que el panel compruebe la API central para validar la ruta Web → Backend → PostgreSQL.
- **HU-005**: Como equipo de seguridad, quiero que los secretos y configuraciones sensibles estén separados del código para reducir exposición accidental.

## Historias principales de producto

- Como tutor, quiero iniciar sesión con Google para acceder de forma segura a NetProtect.
- Como usuario autenticado, quiero seleccionar Tutor o Supervisado para usar la misma aplicación según mi contexto autorizado.
- Como tutor, quiero generar un código temporal de seis dígitos para vincular un dispositivo.
- Como supervisado, quiero introducir el código del tutor para vincular mi dispositivo de forma legítima.
- Como tutor, quiero ver mis dispositivos vinculados para administrar cada uno por separado.
- Como tutor, quiero bloquear o permitir aplicaciones para aplicar políticas de uso.
- Como tutor, quiero configurar listas blanca y negra para controlar aplicaciones y navegación.
- Como tutor, quiero establecer horarios y límites para restringir el tiempo de uso.
- Como tutor, quiero activar modo escolar para priorizar aplicaciones y contenidos educativos.
- Como tutor, quiero consultar la ubicación del dispositivo para conocer su última posición autorizada.
- Como tutor, quiero crear geocercas para recibir eventos de entrada y salida.
- Como tutor, quiero recibir alertas relevantes para detectar incumplimientos o eventos de seguridad.
- Como tutor, quiero consultar historial y estadísticas para analizar patrones de uso.
- Como supervisado, quiero que las reglas sigan funcionando sin Internet para mantener la política vigente.
- Como auditor, quiero consultar acciones administrativas para mantener trazabilidad.
