# Priorización

## Criterios

Cada epic se evalúa por: valor para el objetivo académico, dependencia técnica, reducción de riesgo, seguridad, privacidad, complejidad y viabilidad Android.

## Orden de construcción

1. Arquitectura y ambientes.
2. Base de datos.
3. Autenticación.
4. Roles/RBAC.
5. Vinculación.
6. Dispositivos.
7. Motor y reglas de aplicaciones.
8. Navegación y listas.
9. Tiempo y modo escolar.
10. Ubicación y geocercas.
11. Historial, estadísticas y alertas.
12. Tiempo real y offline.
13. Detección de manipulación.
14. Hardening y auditoría.
15. Supervisión remota sólo después de validar APIs/políticas.
16. Pruebas, despliegue y documentación final.

## Regla de alcance

La supervisión de pantalla, cámara y audio no condiciona el MVP. Si una API, política de Google Play, requerimiento de consentimiento o complejidad impide una implementación responsable, la función se mueve a V2/Futuro sin debilitar el núcleo de control parental.
